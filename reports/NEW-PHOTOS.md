# Genuine La Chingada photography — October 14, 2026

Thirteen photographs were sourced for this visual pass from the restaurant's public WordPress media library at `https://lachingada.ca/wp-json/wp/v2/media`, including a higher-resolution version of the existing bar photograph. The live homepage was inspected first; it contains only the photographs already present in this repository. The official library includes genuine food, cocktails, patio and interior photography, alongside illustrations and generated concepts. Only the photographic candidates listed below were added to the website assets.

All added assets are WebP with intrinsic dimensions, responsive width variants and no upscaling. They preserve the original colours and content. Each photograph was visually checked against its source. Full source URLs, official media IDs/titles, suggested alt text, output dimensions and byte sizes are recorded in [new-photo-manifest.json](new-photo-manifest.json). The [contact sheet](new-photos-contact-sheet.jpg) shows the approved set.
